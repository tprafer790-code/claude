# Habilidades de estudio actualizadas

Versiones revisadas de las cuatro habilidades del entorno de estudio, adaptadas a *Aprender a aprender* (Héctor Ruiz Martín) y al TDA.

| Habilidad | Cambios principales |
|---|---|
| `estudio-orquestador` | Tabla de los seis principios (relaciona, recuerda, olvida, céntrate, confía, colabora) como reglas obligatorias; regla TDA; estructura fija de sesión (ritual de foco → evocación → refuerzo → nuevo → cierre); materiales "hechos" solo como clave tras evocar; paquetes nuevos (Evocación espaciada, Entrelazado, Equipo, Confianza); 140 agentes. |
| `agentes-estudio-parte-1` | Resúmenes, mapas y chuletas con modo previo de memoria; tarjetas que exigen responder antes de voltear; agente 32 con criterio 3/3 en días distintos; problemas mezclados y rehechos sin mirar. |
| `agentes-estudio-parte-2` | Planificador hacia atrás con estimación al alza y entrelazado; sesiones de foco cortas sin distractores; control de progreso con contador 0/3–3/3; estrés de examen con técnicas con evidencia (EFT como opción personal señalada). |
| `agentes-estudio-parte-3` | Gamificación que premia el esfuerzo; nueva sección Q con agentes 131-140 (evocación de apertura, activador de conocimientos previos, autoexplicación, entrelazador, contador de evocaciones, higiene atencional, descarga de memoria de trabajo, mentalidad de crecimiento, evocación en equipo, detector de antitruquis). |

## Cómo instalarlas en claude.ai

1. Abre claude.ai → **Configuración** → **Capacidades** → **Habilidades**.
2. Busca cada habilidad antigua (por ejemplo `estudio-orquestador`) y bórrala o usa la opción de reemplazar.
3. Pulsa **Subir habilidad** y elige el archivo correspondiente de la carpeta `zips/`.
4. Repite con las cuatro.
